Formatos conferidos em arquivos reais (só estrutura e campos, nunca lendo conversas para guardar). **Os formatos são internos das ferramentas e mudam sem aviso**: se uma fonte parar de aparecer após uma atualização da ferramenta, o adaptador precisa ser revisto.

## Observações

- Pastas de trabalho: o `cwd` é reduzido ao último nome de pasta; worktrees (`<repo>/.claude/worktrees/x`) contam para o repositório. Internamente as pastas são separadas pelo caminho completo normalizado (nunca publicado). Duas pastas com o mesmo nome em lugares diferentes só são somadas se o nome público for dado pelo **nome** da pasta (e o `export`/`publish`/`report` avisam); para escolher só uma, use o caminho completo em `publicProjects`.
- Limites de segurança dos adaptadores: datas só de 2000-01-01 até amanhã, tokens inteiros de até 1 bilhão por campo, `.jsonl` até 512 MiB e linhas até 16 MiB, `.messages.json` do Cline até 64 MiB e só dentro de `~/.cline`, caminho de projeto (`cwd`) até 4096 caracteres (acima disso vira "(sem projeto)"). O que passa do limite é descartado com aviso. Os bancos SQLite são abertos somente para leitura.
- Datas em UTC.
- Há registros do Claude Desktop (`~/AppData/Roaming/Claude*`) que não foram avaliados.
